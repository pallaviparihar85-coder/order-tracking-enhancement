# Real-Time Order Tracking Enhancement

## Role
Business Analyst — Self-Initiated Project

## Domain
Food Delivery Application

## Methodology
Agile / Scrum

## Business Problem
Customers had limited visibility into their order and
delivery status, leading to frequent customer support
queries and a poor delivery experience.

## Objective
Improve customer visibility into order progress and
strengthen communication through order-status updates
and notifications.
